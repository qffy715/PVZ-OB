常见问题

FAQ

OrderBreak 是什么？

OrderBreak 是《植物大战僵尸》一代的粉丝自制改版，核心改动是僵尸机制重做与数值再平衡，目标是给老玩家一套全新的对局体验。

现在能下载玩到吗？

目前 v0.1 仍在开发中。安装包发布后，会第一时间在 GitHub Releases 页面上架，本官网"游戏下载"区也会同步入口。

改版会影响原版游戏吗？

不会。OrderBreak 是独立的改版包，不会修改你电脑上的原版游戏文件。

这是官方作品吗？

不是。OrderBreak 为粉丝自制、非商业性质，与 PopCap / EA 无任何关联，《植物大战僵尸》相关素材版权归原作者所有。
