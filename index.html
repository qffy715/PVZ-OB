植物大战僵尸：破序是什么？

《植物大战僵尸：破序》（Plants vs. Zombies: OrderBreak）是《植物大战僵尸》一代的非商业粉丝改版：49 株植物机制重构、普通与精英僵尸改造、阶段化僵王博士战、多款小游戏新玩法，同时保留原版美术氛围。

目前可以下载吗？

最新 v1.0.1 RC1 已通过指定 Windows 实机测试；网站尚未上架可公开下载的 GitHub Release，请留意本页与仓库更新。

需要哪个基础版本？

Plants vs. Zombies 1.0.0.1051 EN。改版 EXE 需要与对应的原版 main.pak、bass.dll 放在同一游戏目录下运行。

需要联网或账户吗？

不需要。游戏本体为纯单机，运行时无需在线登录。

会覆盖原版吗？

安装时不应覆盖原版 PlantsVsZombies.exe，也不要替换 main.pak。但如果使用相同的玩家存档目录，仍可能存在数据交互或覆盖风险，请先备份存档。

精英僵尸如何区分？

通过外观变化、不同的护甲与速度和专属机制区分；完整数值与图鉴筹备中。

这是官方作品吗？

不是。破序为粉丝自制、非商业性质，与 PopCap / EA 无任何官方关联；《植物大战僵尸》相关权利归其权利人所有。
